# Hik2Adhai Cafe Website

A single-page website for **Hik2Adhai Cafe** in Phase-I, Jamshoro, Pakistan: a cozy spot for coffee, chai, drinks, and conversation.

## Features

- **Self-contained**: all styles, scripts, fonts, and images are embedded in one `index.html`
- **Responsive design** for phones, tablets, and desktops
- **Menu, gallery, and reviews sections**, with a full-screen image lightbox
- **Location section** with "Open in Google Maps" and sticky directions buttons
- **Contact form** (front end, ready to connect to a form service)

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

```bash
git clone https://github.com/ztuniio/hik2adhai.git
cd hik2adhai
```

Then open `index.html` in your browser. There is nothing to install.

## Deployment

Host it on GitHub Pages (**Settings → Pages → Deploy from a branch → `main` / root**), Vercel, or Netlify.
